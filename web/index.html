原有数据为 4 名说话人录制的 1,200 条语音。真实录音、新说话人、口音、噪声和复杂情绪可能降低准确率。网页显示的模型置信度不是实际正确率，低置信度结果会明确标注。

音频与隐私

音频发送至你当前运行的服务，用于本次模型推理。服务处理结束后删除上传临时文件；会话记录保存在当前页面内存中，导出由你主动触发。模型推理不需要向外部识别 API 发送音频。
